# 01 · 产品概述

## 产品定位

**Landlord** 是一款横屏斗地主手游，目标是提供一个**干净、流畅、可扩展**的斗地主体验：从单机与人机对战起步，逐步扩展多种玩法与联网对战。

差异化方向不追求「氪金社交」，而是：
- **本地优先**：单机模式下零网络、零延迟、可离线。
- **规则严谨**：完整实现标准斗地主 14 种牌型与比较规则（见 [04-game-rules.md](./04-game-rules.md)）。
- **可成长的 AI**：AI 策略可从规则启发式逐步升级到 MCTS / 强化学习模型。
- **可扩展架构**：玩法（变体）、AI、网络层相互解耦，新增玩法不改核心。

## 目标用户

| 用户画像 | 核心需求 | 痛点 |
|----------|----------|------|
| **休闲玩家**（主力） | 随时随地来一局，规则标准，操作顺手 | 市面游戏广告多、强制社交、节奏拖沓 |
| **进阶玩家** | 想赢、想研究牌技、可调难度 | AI 太弱或作弊感强（看穿手牌） |
| **好友组局** | 约两三朋友线上打牌 | 房间难建、断线重连差 |

## 商业/项目目标

本项目定位为**个人/学习型产品**（暂不商业化），目标：
1. 完成一个工程结构清晰、可作为 Flutter 游戏开发参考模板的项目。
2. 实现一个具备真实可玩性的斗地主（单机优先）。
3. 积累卡牌游戏 AI 与实时联网的工程经验。

> 如未来转向商业化，需补充：防作弊、未成年人保护、支付合规等，本阶段不展开。

## 成功指标（Phase 1，单机 MVP）

| 指标 | 目标 |
|------|------|
| 规则正确性 | 14 种牌型识别与比较 100% 通过单元测试 |
| 启动到开局耗时 | < 1 秒 |
| AI 出牌响应 | 简单（启发式）< 10ms，普通（PIMC）< 1s，困难（DouZero）< 100ms |
| 帧率 | 横屏下稳定 60fps |
| 崩溃率 | 单局对战中 0 崩溃 |

## 产品原则

1. **离线优先**：单机模式不需要任何网络权限即可运行。
2. **可暂停可恢复**：对局状态可序列化，App 切后台/回前台不丢局。
3. **不欺骗玩家**：AI 仅基于可见信息推理（PIMC 采样），不直接读取玩家手牌（见 [06-ai-strategy.md](./06-ai-strategy.md) 的「公平性」一节）。
4. **横屏体验**：UI 按横屏比例设计，桌面端（Web/桌面）同样适用。

## 未来愿景

- **跨平台**：移动端为主，天然支持桌面与 Web（Flutter 优势）。
- **可插拔玩法**：通过「玩法配置」描述变体规则，而非硬编码分支。
- **AI 升级路径**：预留模型接入接口，未来可加载预训练的 DouZero 权重（见 [06](./06-ai-strategy.md)）。
